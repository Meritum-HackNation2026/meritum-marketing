# Film demonstracyjny

Wymaganie: film pod linkiem, najwyżej 3 minuty.

- `scenariusz.md`: scenariusz z podziałem na ujęcia i czasy,
- `link.txt`: link do opublikowanej wersji (to on trafia do zgłoszenia),
- pliki wideo (`.mp4`, `.mov`, `.webm`) idą przez Git LFS (`.gitattributes`). Przed pierwszym commitem wideo uruchom `git lfs install`.

Plan demo z `design-system/PRODUCT.md`: to samo pytanie w formularzu WWW i pod postem na makiecie X przez wtyczkę, werdykt ze źródłami, uczciwe wstrzymanie się ze sprawą dla moderatora, zignorowana próba wstrzyknięcia poleceń i wyniki ewaluacji na naszym zestawie testowym (zestaw referencyjny MSZ jest dla nas ukryty). Makiety do nagrań: https://meritum-x.gburek.app (i pozostałe platformy).
