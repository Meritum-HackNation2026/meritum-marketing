# Materiały do mediów społecznościowych

Gotowe pliki PNG w rozmiarach: obraz do linków 1200×630, post 1080×1080, story 1080×1920, baner LinkedIn 1584×396. Źródła HTML, z których się je generuje, są w `design-system/presentation/social/`, a logo w `design-system/brand/exports/`.

Obecne grafiki w design-system mają jeszcze stary podtytuł („…oraz scamu”). Tu wrzucamy tylko wersje z podtytułem „obywatelski radar dezinformacji”.
